Engine Internals

底层执行与多层编译流水线

结合 ANTLR4 抽象语法树、堆栈虚拟机冷启动与 LLVM 原生 JIT 编译器的多层执行拓扑。

执行流水线 (Execution Pipeline)
PHASE 01
ANTLR4 前端解析
高精度语法分析构建 AST 抽象语法树，支持递归访问者模式。
PHASE 02
Tier 0 虚拟机
堆栈字节码执行，多态内联缓存 (PIC) 与 .tzdc 指令序列化毫秒级冷启动。
PHASE 03
热点探测 Profiler
追踪调用计数 (>=50) 与回边计数 (>=1000)，触发后台线程池异步编译。
PHASE 04
Tier 1 LLVM JIT
mem2reg、EarlyCSE、硬件 idiv 特化指令，直接生成 x86_64 极速机器码。
新生代 Bump Pointer Arena

以 64KB 为块大小进行指针碰撞线性推进分配，分配复杂度严格维持在 O(1)。在生命周期结束时整块回收，完全规避传统堆内存碎片与高频 malloc 开销。

老年代 SATB 三色标记 GC

长生命周期对象进入老年代，采用集成 SATB（Snapshot-At-The-Beginning，原始快照）写屏障的三色标记清除算法。在并发标记期间拦截引用指针更新，防止对象丢失。
